# Brand assets

Official Variation 01 assets (PNG sources) plus SVG traces.

| File | Use |
| --- | --- |
| `mark.png` | Primary mark (transparent) |
| `mark.svg` | Vector trace of the mark |
| `mark-current.svg` | Mark using `currentColor` |
| `app-icon.png` / `app-icon-512.png` | App / home-screen icon |
| `apple-touch-icon.png` | iOS home screen |
| `wordmark.png` | Mark + wordmark (light bg) |
| `wordmark-on-dark.png` | Light mark + wordmark (dark bg) |
| `logo-stacked.png` | Mark above wordmark |
| `favicon-mark.png` | Favicon from the mark |

React: `BrandMark`, `BrandMarkOnDark`, `BrandWordmark` in `src/components/BrandMark.tsx`.

Colors sampled from the assets: ink `#0F1827`, gray `#4F5561`.
